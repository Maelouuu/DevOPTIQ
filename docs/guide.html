L'entité active — votre "lentille" de travail

Choisir son entité active

DevOPTIQ est une plateforme multi-entités : vous pouvez gérer plusieurs organisations depuis un seul compte (un département, une filiale, une équipe…). L'entité active est celle sur laquelle vous travaillez à l'instant T. Elle agit comme un filtre global : tout ce que vous voyez (activités, rôles, compétences) appartient à cette entité.

Vous changez d'entité depuis la page Cartographie en cliquant sur l'entité souhaitée dans le panneau de gauche. Ce choix persiste pendant toute votre session.

2. La Cartographie OptiqCarto

Le cœur de DevOPTIQ. Dessinez, organisez et versionnez vos processus métier en quelques clics.

Qu'est-ce qu'une cartographie ?

Une cartographie est une carte visuelle de vos processus métier, organisée en bandes horizontales (les rôles ou niveaux hiérarchiques) avec des boîtes représentant chaque activité et des flèches indiquant les flux entre elles. C'est à partir de cette carte que DevOPTIQ structure toute votre base de données : activités, tâches, compétences et ressources humaines.

L'éditeur OptiqCarto

L'éditeur est un outil SVG interactif entièrement maison. Il vous permet de créer et modifier votre cartographie directement dans le navigateur, sans logiciel externe.

  • 1Bandes (rôles) — Créez des bandes horizontales pour organiser vos activités par niveau ou par service
  • 2Activités — Ajoutez des boîtes dans les bandes pour représenter chaque processus
  • 3Connexions — Reliez les activités par des flèches pour matérialiser les flux
  • 4Synchronisation — Cliquez sur "Sauvegarder" pour mettre à jour la base de données automatiquement
Vous pouvez importer un fichier .vsdx (Microsoft Visio) pour démarrer depuis un diagramme existant plutôt que de partir de zéro.
Multi-entités — une base par organisation

Une base de données par entité, mais interconnectée

Chaque entité possède sa propre base de données indépendante : ses activités, ses rôles, ses tâches, ses collaborateurs et ses compétences lui appartiennent exclusivement.

Cependant, les entités peuvent se référencer mutuellement dans leurs cartographies via les activités externes (extco). Par exemple, la Direction Financière peut afficher dans sa carto l'activité "Système d'information" gérée par la DSI, sans dupliquer les données — c'est un lien, pas une copie.

Les activités extco apparaissent en pointillés dans l'éditeur pour les distinguer des activités propres à l'entité.
Calques — versionnez votre organisation

Les calques : plusieurs versions de votre carto

Un calque est une version alternative ou un instantané de votre cartographie principale. Pensez-y comme aux branches dans Git : votre organisation actuelle est la branche principale, et les calques sont des branches de test ou de planification.

Scénarios futurs

Testez une réorganisation avant de la valider officiellement.

Historique

Gardez une trace de votre organisation passée pour comparaison.

  • 1Dans l'éditeur, cliquez sur Calques dans la barre d'outils
  • 2Cliquez sur + Nouveau calque et donnez-lui un nom
  • 3Modifiez librement ce calque — la carto principale reste intacte
  • 4Basculez entre calques depuis le panneau latéral gauche
Import Visio (.vsdx) : Si votre organisation dispose déjà de diagrammes Microsoft Visio, vous pouvez les importer directement dans OptiqCarto. Les formes, bandes et connexions sont automatiquement reconnues et converties. Glissez-déposez votre fichier .vsdx ou utilisez le bouton "Importer…" dans la barre d'outils de l'éditeur.
Sélection & Groupement avancés

Sélection lasso

Activez l'outil lasso dans la barre d'outils, puis dessinez un rectangle de sélection sur le canvas en cliquant-glissant. Toutes les activités couvertes sont sélectionnées simultanément et peuvent être déplacées ou groupées ensemble. Le lasso se désactive automatiquement après chaque sélection.

Piles d'activités

Regroupez plusieurs activités connexes dans une pile (conteneur pliable). Une pile peut être réduite pour afficher une vue compacte, ou déployée pour montrer toutes les activités individuelles. Les connexions (ports) restent persistantes lors du pliage/dépliage — les flux sont préservés.

Les piles sont particulièrement utiles pour les cartographies denses : elles permettent de simplifier la vue d'ensemble sans perdre d'information sur les flux entre groupes d'activités.

3. Activités & Tâches

Chaque activité de votre carte devient une fiche détaillée : tâches, outils, connexions, compétences et bien plus.

La liste des activités

La page Activités affiche toutes les activités de votre entité active, sous forme de cartes extensibles. Chaque carte donne accès à l'ensemble des informations de l'activité : tâches, connexions, compétences, temps…

  • 1Cliquez sur le nom d'une activité pour l'ouvrir
  • 2Naviguez entre les onglets pour accéder aux différents aspects
  • 3Utilisez la barre de recherche pour filtrer par nom
Ce que contient chaque fiche activité

Tâches

Liste ordonnée des actions à effectuer, avec les outils utilisés et les rôles impliqués. Chaque tâche peut être réordonnée par glisser-déposer.

Connexions

Flux entrants et sortants depuis/vers d'autres activités. Chaque connexion peut recevoir des indicateurs de performance (KPIs).

Compétences

Compétences génériques requises pour réaliser l'activité, avec niveau de maîtrise attendu.

Savoirs & SF

Connaissances théoriques (Savoirs) et compétences pratiques (Savoir-Faires) liées à l'activité.

Aptitudes & HSC

Aptitudes latentes et Habiletés Socio-Cognitives (soft skills) selon la norme NF X50-766.

Contraintes

Contraintes réglementaires, techniques ou organisationnelles qui encadrent l'activité.

4. L'Écosystème des Compétences

5 types de compétences, évaluation multi-évaluateurs et plans de formation personnalisés.

Les 5 types de compétences

DevOPTIQ utilise un modèle de compétences à 5 niveaux, du plus général au plus spécifique. Chaque activité peut se voir associer des éléments de chacun de ces 5 types.

1

Compétences génériques

Compétences globales et transversales (ex: "Gestion de projet", "Communication")

2

Savoirs — Connaissances théoriques

Connaissances formelles requises (ex: "Normes IFRS", "Code du travail")

3

Savoir-Faires — Compétences pratiques

Capacités à agir avec des verbes d'action (ex: "Configurer SAP FI", "Analyser un bilan")

4

Aptitudes

Capacités latentes et dispositions naturelles (ex: "Rigueur analytique", "Adaptabilité")

5

HSC — Habiletés Socio-Cognitives IA

Soft skills normalisés NF X50-766, niveaux 1 à 4 (ex: "Communication interpersonnelle – niveau 3")

Évaluation des compétences — le système multi-évaluateurs

Trois regards, une vision complète

Chaque compétence peut être évaluée par jusqu'à 3 évaluateurs différents, apportant des points de vue complémentaires :

Garant

Le responsable de l'activité, qui connaît le métier en profondeur.

Manager

Le manager direct (global ou assigné par rôle).

RH

La fonction RH, pour une vision institutionnelle du collaborateur.

Les évaluations sont indépendantes : chaque évaluateur saisit son appréciation sans voir celle des autres, garantissant l'objectivité.

Plans de formation Générés par IA

Plan FORMATION

Déclenché sur les compétences "à développer" (rouge). Propose des formations concrètes avec calendrier et méthodes de validation.

5. Intelligence Artificielle

Chatbot, propositions automatiques, import Excel intelligent et plans de formation — l'IA est partout dans DevOPTIQ.

Chatbot assistant de saisie

Le chatbot intégré vous aide à décrire et structurer les tâches d'une activité. Dialoguez en langage naturel : il vous pose des questions, propose des formulations et génère une liste de tâches conforme aux bonnes pratiques OPTIQ.

Le chatbot respecte des règles OPTIQ strictes : 5 à 8 tâches par activité, un seul verbe d'action par tâche, pas d'étapes procédurales. Il applique aussi le protocole "Ça dépend" pour les cas conditionnels.
  • 1Ouvrez une fiche activité et cliquez sur l'onglet Tâches
  • 2Cliquez sur l'icône chatbot
  • 3Décrivez l'activité en langage naturel
  • 4Validez les tâches proposées pour les injecter automatiquement
Propositions de compétences par IA

Sur chaque fiche activité, des boutons "Proposer…" permettent de générer automatiquement des suggestions de compétences adaptées au contexte de l'activité. L'IA analyse le nom, les tâches et les outils pour formuler des propositions pertinentes.

Savoirs

Génère des connaissances théoriques nominales adaptées à l'activité.

Savoir-Faires

Propose des compétences pratiques formulées avec des verbes d'action.

HSC / Soft Skills

Suggère des Habiletés Socio-Cognitives conformes NF X50-766, avec niveau et justification.

Aptitudes

Identifie les aptitudes latentes et dispositions requises pour réussir dans l'activité.

Import Excel intelligent Matching 3 passes

Importez votre référentiel depuis Excel

Disposez d'un fichier Excel avec vos activités, tâches et outils ? L'import IA analyse votre fichier et injecte automatiquement les données dans DevOPTIQ, en faisant correspondre les entrées Excel à vos activités existantes via un algorithme de matching en 3 passes.

6. Gestion RH & Rôles

Gérez vos collaborateurs, leurs rôles, leurs managers et leurs plans d'onboarding.

Gestion des rôles

Créez les rôles de votre entité (ex: "Comptable Senior", "Chef de Projet"). Chaque rôle a une mission générale et peut être assigné à plusieurs collaborateurs. Les rôles structurent les bandes dans votre cartographie.

Gestion des collaborateurs

Ajoutez vos collaborateurs un par un ou en masse (import JSON). Assignez-leur un ou plusieurs rôles, un manager et un statut. Leurs accès à l'application sont configurés ici.

Hiérarchie managériale

Deux niveaux de management : un manager global pour toute l'entité, et des managers par rôle pour un pilotage plus fin. Chaque manager peut évaluer les compétences de ses équipes.

Garant d'activité

Chaque activité peut désigner un rôle comme Garant : c'est le responsable métier de l'activité. Le Garant apparaît dans les fiches et les exports, et peut évaluer les compétences associées.

Plans d'onboarding Générés par IA

Pour chaque rôle, DevOPTIQ peut générer automatiquement un plan d'onboarding en 4 modules, exclusivement centré sur les Habiletés Socio-Cognitives (HSC) transmises par le contexte de l'activité. Le plan inclut la durée, les méthodes pédagogiques et les jalons de validation.

Module 1
Formation

Formations courtes ciblées sur les HSC prioritaires (0,5 à 2 jours max).

Module 2
REX

Session de Retour d'Expérience avec les pairs pour ancrer les apprentissages.

Module 3
Coaching

Stratégies de coaching en équipe pour développer les habiletés socio-cognitives.

Module 4
Autonome

Parcours d'apprentissage autonome : lectures, e-learning, mise en pratique.

Import en masse : Importez tous vos collaborateurs en une seule opération via un fichier JSON structuré (prénom, nom, e-mail, âge, mot de passe, rôle, statut). Les doublons sont automatiquement détectés par e-mail.

7. Performance & KPIs

Suivez les indicateurs de performance sur vos connexions et évaluez la performance individuelle de vos collaborateurs.

KPIs sur les connexions

Dans DevOPTIQ, les indicateurs de performance (KPIs) sont attachés aux connexions entre activités (les flèches de votre carto). C'est une approche orientée flux : on mesure la qualité de la transmission entre deux processus plutôt que l'activité seule.

  • 1Ouvrez une fiche activité et allez dans l'onglet Connexions
  • 2Cliquez sur le bouton "+ KPI" à côté d'une connexion
  • 3Saisissez le nom, l'unité et la valeur cible de l'indicateur
  • 4Mettez à jour la valeur réelle régulièrement pour suivre la progression
Performance personnalisée par collaborateur

Au-delà des KPIs d'activité, vous pouvez suivre la performance individuelle de chaque collaborateur sur une activité donnée. Ces évaluations passent par un circuit de validation (en attente → validé / rejeté) avec un audit trail complet qui trace chaque modification.

En attente

L'évaluation est soumise et attend validation par un manager ou RH.

Validée

L'évaluation est approuvée et intégrée dans le suivi du collaborateur.

Historique complet

Chaque modification est tracée (qui, quand, quelle valeur) pour une auditabilité totale.

8. Gestion du Temps

Planifiez les charges par projet, par activité et par rôle. Détectez les surcharges avant qu'elles n'arrivent.

Vue Projet

Planifiez le temps alloué à des projets transverses : durée totale, récurrence, répartition par ligne de projet. Idéal pour les projets de transformation ou réglementaires.

Vue Activité

Définissez la durée et la fréquence de chaque activité (journalier, hebdo, mensuel, annuel). DevOPTIQ calcule automatiquement la charge totale par rôle.

Vue Rôle

Agrège toutes les charges par rôle et compare avec la capacité disponible (heures/jour × jours/semaine × semaines/an). Identifie les rôles surchargés ou sous-utilisés.

Détection des Faiblesses

Modèle probabiliste qui identifie les risques de goulots d'étranglement. Des variables pondérées calculent l'exposition aux surcharges et aux sous-staffings.

Visualisez la charge de vos rôles

La vue Rôle affiche pour chaque rôle un taux d'occupation en pourcentage de la capacité disponible. Trois codes couleur permettent d'identifier d'un coup d'œil les problèmes :

< 80%

Capacité disponible — charge saine.

80–100%

Proche de la limite — vigilance requise.

> 100%

Surcharge — action corrective requise.

Le calendrier de référence (heures/jour, jours/semaine, semaines/an) est configurable dans les Paramètres d'entité sous Gestion RH.

Export HTML autonome

En plus de l'Excel, DevOPTIQ peut générer une page HTML standalone : un fichier unique, auto-contenu (CSS embarqué), entièrement imprimable et partageable sans avoir besoin d'accès à l'application.

Idéal pour diffuser un référentiel figé à un partenaire ou un auditeur externe.

Les fichiers exportés sont stockés directement en base de données (PostgreSQL BYTEA) — aucun fichier temporaire sur le serveur, compatible avec l'environnement Cloud Run éphémère.

Glossaire

Les termes clés de DevOPTIQ expliqués simplement.

Entité

Une organisation gérée dans DevOPTIQ (département, filiale, équipe). Chaque entité a sa propre cartographie et sa propre base de données.

Cartographie

Représentation visuelle SVG des processus métier d'une entité, organisée en bandes (rôles) et activités reliées par des connexions.

Calque

Version alternative d'une cartographie. Permet de tester des scénarios ou de conserver un historique sans toucher à la carto principale.

Extco (activité externe)

Activité d'une autre entité référencée dans votre cartographie. Apparaît en pointillés et crée un lien cross-carto sans dupliquer les données.

Garant

Rôle désigné comme responsable d'une activité. Le Garant peut évaluer les compétences et apparaît dans les exports.

HSC

Habiletés Socio-Cognitives — soft skills normalisés selon la norme NF X50-766, avec 4 niveaux de maîtrise et des catégories officielles.

Savoir / Savoir-Faire

Savoir = connaissance théorique formelle. Savoir-Faire = compétence pratique formulée avec un verbe d'action (ex : "Analyser un bilan").

Connexion / Lien

Flux directionnel entre deux activités dans la cartographie. Les connexions peuvent recevoir des KPIs pour mesurer la qualité du flux.

KPI

Indicateur clé de performance attaché à une connexion entre activités. Permet de mesurer et suivre la qualité d'un flux de données ou de travail.

Calque de temps

Unité de planification des temps : activité à fréquence journalière, hebdomadaire, mensuelle ou annuelle, avec durée unitaire et rôle associé.
