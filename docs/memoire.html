Chronologie du projet

12 phases majeures identifiées depuis le commit initial sur le dépôt Colmar (colasmar) jusqu'au déploiement Cloud Run sur maelouuu, avec les commits Claude Code CI/CD comptabilisés intégralement.

Déc. 2024 — Dépôt Colmar
🚀 Initial commit & Structure Flask
Création du dépôt sur le compte colasmar. Flask + SQLite + SQLAlchemy. Routes blueprints, affichage activités en volet déroulant. Import Visio (.vsdx) fonctionnel en lecture. Premier modèle de données Activity.
Flask SQLite VSDX v1 12 commits
Fév. 2025 — Itération 2
⚙️ Gestion des tâches & glisser-déposer
Modèle Task + association activities↔tasks. Import des tâches via bouton dédié. Glisser-déposer sur la liste d'activités. Premières migrations Alembic locales. Correction de la gestion des flux VSDX.
Tâches Alembic 13 commits
Jun. – Août 2025
🧠 Compétences, ROME 4.0 & Propositions IA
Intégration API France Travail pour le matching ROME 4.0. Module compétences complet : savoir, savoir-faire, aptitudes, softskills. Premiers appels OpenAI GPT-4o-mini pour des propositions contextuelles. Page gestion des outils (gestion_outils.py), page rôles. Analyse des temps (3 tableaux).
OpenAI GPT ROME 4.0 Compétences 15 commits
Oct. 2025 — Changement d'hébergement
☁️ Dockerisation & mise en ligne Cloud Run
Passage sur le dépôt personnel maelouuu (plus simple pour le déploiement solo). Dockerfile + .dockerignore. Base de données migrée vers PostgreSQL Neon Cloud. Variables d'environnement Cloud Run (DATABASE_URL, clés API). Premier déploiement Google Cloud Run réussi.
Docker Cloud Run PostgreSQL → maelouuu
Nov. – Déc. 2025
🏢 Logique d'entités & Séparation des cartographies
Ajout du modèle Entity (département, service…). Chaque entité possède sa propre cartographie SVG indépendante. Refonte des routes propose_* avec fallback sans clé OpenAI. PR Colasmar #9 et #14 fusionnées. Page Visio dédiée. 21 commits dont collaboration externe.

Refonte complète de la page activités v1 (janv.) Merge Colasmar→main. Import Guarantor, refonte popup carto. Migration technique vers dépôt maelouuu avec ajout des colonnes svg_content + vsdx_filename en DB (auto-migration cloud). Stockage SVG en base pour Cloud Run (filesystem éphémère).
