Chronologie du projet

Les grandes étapes de DevOPTIQ, du commit initial sur le dépôt Colmar jusqu'à la version Cloud Run complète sur le dépôt maelouuu.

Décembre 2024
🚀 Initial commit — Dépôt Colmar
Initialisation du dépôt sur le compte Colmar. Structure de base : Flask, SQLite, première page HTML affichant des activités en volet déroulant. Import Visio (.vsdx) fonctionnel en lecture. Routes avec blueprints.
Flask SQLite VSDX v1
Février 2025
⚙️ Itération 2 — Gestion des tâches
Ajout du modèle Task, gestion des outils, glisser-déposer sur la liste d'activités. Import des tâches via bouton dédié. Premières migrations Alembic locales.
Tâches Alembic local
Juin – Août 2025
🧠 Compétences, ROME 4.0 & Propositions IA
Page de gestion des compétences (savoir, savoir-faire, aptitudes, softskills). Intégration de l'API France Travail pour le matching ROME 4.0. Premiers appels OpenAI GPT pour des propositions contextuelles. Page gestion des outils et des rôles.
OpenAI GPT ROME 4.0 Compétences
Octobre 2025
☁️ Mise en ligne — Cloud Run + PostgreSQL
Passage sur le dépôt personnel maelouuu (plus simple pour le déploiement solo). Dockerisation de l'application. Base de données migrée vers PostgreSQL Neon Cloud. Premier déploiement Google Cloud Run.
Docker Cloud Run PostgreSQL → maelouuu
Novembre – Décembre 2025
🗂️ Entités & Séparation des cartographies
Ajout de la logique d'entités organisationnelles (département, service). Chaque entité a sa propre cartographie SVG. Refonte des routes propose_*, collaboration Colasmar via PR, fusion branches.
Entités Multi-carto PR Colasmar
Janvier – Mars 2026
♻️ Refonte UI & Navigation cross-carto v1
Refonte complète de la page activités. Ajout de la navigation inter-cartographies (popup SVG preview). Gestion RH complète (managers, rôles, CSV). Import IA Excel multi-passes (exact/inclusion/fuzzy).
Cross-carto v1 Import Excel IA Gestion RH
Avril 2026
📁 Fichiers liés, Changelog IA & Cross-carto
Stockage de fichiers en DB (FileBlob, cloud-native). Export Excel 6 feuilles + HTML standalone. Popup nouveautés Changelog généré par GPT. Navigation entre cartos via iframe. Page compte complète avec import JSON.
FileBlob DB Export Excel/HTML Cross-carto iframe
Mai 2026 — Semaine 1–2
🤖 CI/CD + VSDX Diamants + Architecte IA
Mise en place des GitHub Actions (staging + production). VSDX : import des losanges de décision (Oui/Non). Architecte IA (OpenAI) pour l'alignement automatique des formes. Bandes métier par défaut (15 bandes), bulk creation.
CI/CD VSDX Diamants Architecte IA
Mai 2026 — Semaine 3
🧪 Calques + 404 tests unitaires
Système de calques (variants de cartographies) complet DB + API + JS. Auto-save 10 min + avertissement modifications non enregistrées. Campagne de tests : 404 tests unitaires ajoutés en 10 jours couvrant 30+ modules.
Calques 404 tests
Mai 2026 — Semaine 4
🌐 i18n + Liaisons inter-carto complètes + VSDX finalisé
Système d'internationalisation (i18n) couvrant toute l'app. Mode connexion inter-cartographies complet : clic iframe, popup preview, officialisation DB. VSDX : routage orthogonal, géométrie Visio, losanges Oui/Non finaux. Navbar liquid glass. Flèches 2D avec coins éditables.
i18n Liaisons cross-carto VSDX final Flèches 2D
